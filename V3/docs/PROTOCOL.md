# V3 protocol specification

## Required packet contract

Retain raw `CSI_DATA` records with local timestamp, packet sequence/counter,
RSSI, CSI buffer length, raw interleaved I/Q, link identity, channel, and
available radio metadata. Keep the raw lines; amplitude-only exports cannot
reconstruct all V3 diagnostics.

## Processing

1. Parse and validate the record header.
2. Convert interleaved I/Q to amplitude.
3. Retain L-LTF bins and remove dead/spiky subcarriers.
4. Unwrap timestamps and resample the irregular packet stream to 20 Hz.
5. Average collisions in a grid bin; linearly interpolate empty bins and retain
   the `bool[60]` missing mask.
6. Create causal 3-second windows every 1 second.
7. Convert surviving bins to 32 relative-amplitude bins.
8. Run LightGBM features or the CNN/transformer sequence path.
9. Optionally apply site-specific 30-second empty-room calibration.
10. Apply five-window median smoothing only when reporting smoothed results.

## Tensor contract

Deep models receive a sequence shaped `[batch, 32, 60]` and a gap mask shaped
`[batch, 60]`. LightGBM receives the feature-column order generated by
`features.window_features()` and `features.rssi_features()`.

See [esp32_io.py](../src/esp32_io.py), [build.py](../src/build.py),
[preprocess.py](../src/preprocess.py), and [calibrate_v3.py](../src/calibrate_v3.py)
for the implementation.
